# kalshi-paper-status

Auto-published mirror of the status page of a **paper-trading** experiment: simulated maker bids on
short-dated Kalshi favorites, with fills inferred from the public tape. Rendered HTML only — the
code, ledgers and analysis live in a private repository. No real orders, no account, no money at risk.
Not investment advice.

The page is regenerated on the source machine every 5 minutes and mirrored here every 10 minutes.
